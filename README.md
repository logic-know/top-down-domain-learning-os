# Top-Down Domain Learning OS

自上而下领域学习系统（Top-Down Domain Learning OS）——一个 AI Agent Skill。

从用户提出的一个"领域难题"出发，反向构建出理解这个问题所必须掌握的知识体系。最终让用户达到：

> **"我能看懂这个难题到底在研究什么、为什么难、过去怎么解决、现在怎么解决、还有什么没解决。"**

## 这是什么

这不是一门课程，也不是一份百科。它是一个**问题驱动的学习系统提示词/方法论**，以 SKILL.md 的形式封装，可被 AI Agent（豆包、Claude 等支持 Skill 机制的助手）直接加载使用。

## 核心机制

| 模块 | 作用 |
| --- | --- |
| 领域全景 | 先回答"问题属于哪个领域、在研究什么、在问什么、为什么重要、大致解决路线" |
| 最小知识树 | 只保留真正影响理解原问题的知识，不无限扩展 |
| 自上而下逐层讲解 | Level 0 生活语言 → Level 5 研究前沿，一次只下钻一层 |
| 理解检测 | 解释题 / 因果题 / 判断题 / 反例题，禁止只问"明白了吗" |
| 动态下钻 | 掌握→继续；大致理解→补案例再问；混乱→回退一级；基础缺失→先补前置 |
| 已理解 / 待理解区 | 持续维护 ✅ 已理解 / 🟡 基本理解 / 🔴 尚未理解 清单 |
| 解法拆解 | 过去怎么解决 / 现在怎么解决 / 解决到什么程度 / 为什么还没完全解决 |
| 知识卡片 | 生成纯 Markdown 卡片（公式用纯文本，不依赖 LaTeX） |

## 学习控制指令

`@全景` `@下钻` `@退回` `@测试` `@应用` `@回到问题` `@现状` `@知识卡片`

## 使用方法

将 `SKILL.md` 放入 AI 助手的 skills 目录（如 `workspace/.user_skills/top-down-domain-learning/`），即可被加载。随后向助手提出任意领域难题，例如：

- "大模型为什么会产生幻觉？"
- "为什么镜头拍出的照片边缘会模糊变形？"
- "Transformer 为什么需要位置编码？"

## 配套网页应用

本仓库配套一个可直接运行的交互式网页应用「领域学习OS」，实现了本方法论的完整对话式学习体验（演示模式 + 任意 OpenAI 兼容 API），见 [domain-learning-webapp](https://github.com/) 仓库。
